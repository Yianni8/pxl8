# pxl8

A reusable canvas-based text pixelation effect with a small interactive demo.

## Tech stack

- React
- TypeScript
- Canvas 2D API
- Vite
- HTML and CSS

## Development

```bash
npm install
npm run dev
```

The reusable React component and its canvas animation code will live in `src/`.
The showcase will live in `demo/` and consume the same component that other
projects will eventually import.
